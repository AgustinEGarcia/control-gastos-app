# PLAN DE CONTINGENCIA Y FALLBACK MULTI-AGENTE

## Procedimiento de Cambio de Agente si se agota la cuota en Gemini:
1. Abrir panel lateral en AntiGravity y seleccionar **Roo Code** o **Continue**.
2. Ingresar la API Key (OpenRouter, Anthropic o DeepSeek) o conectar con Ollama local.
3. Indicar al agente: *"Lee `docs/PRD.md`, `docs/OPENSPEC.md` y `docs/MEMORY.md` para continuar desde el estado actual."*
