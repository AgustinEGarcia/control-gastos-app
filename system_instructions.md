# Idioma y Comunicación
- El idioma principal de interacción es **Español**.
- Mantén la terminología técnica en inglés solo si es el estándar en programación (ej. *pull request*, *deploy*, *build*).

# Modo Autónomo y Ejecución
- Cuando el usuario solicite implementar una tarea o avanzar, actúa con máxima autonomía de principio a fin.
- No te detengas a pedir aprobaciones intermedias de planes o permisos archivo por archivo: crea, modifica, prueba y completa toda la tarea hasta entregar el resultado listo y probado.
